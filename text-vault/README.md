# Text Vault · 文本暂存匣

油猴（Tampermonkey）脚本：把网页里选中的文本随手存进油猴存储，之后在任何网站一键回填到输入框或复制到剪贴板。适合「在这页看到一段文字，想到另一页的输入框里用它」的跨页面搬运场景。

> 文件：[text-vault.user.js](./text-vault.user.js) · v1.0.0

## ✨ 功能特性

- **选中即记**：选中网页文字后，光标旁浮出「✚ 记」小按钮，点一下就存入油猴存储（`GM_setValue`），全站共享。
- **剪贴板兜底**：油猴菜单「➕ 记录选中文本 / 剪贴板」——没有选中文本时自动改读剪贴板；浏览器拒绝读取时（如点击扩展菜单后页面失焦）弹出手动粘贴框。
- **一键回填**：点击面板条目——页面里有聚焦的输入框（`input` / `textarea` / `contenteditable`）就插入光标处（替换选区，兼容 React/Vue 受控组件）；没有就复制到剪贴板（`GM_setClipboard`）。
- **管理能力**：编辑、删除（5 秒内可撤销）、置顶（★，淘汰和清空时不丢）、搜索过滤、手动新增、去重（重复记录自动置顶并刷新时间）。
- **面板交互**：悬浮球显示条目数，可拖动记忆位置；面板支持明暗主题（跟随系统），Esc / ✕ 关闭，跨标签页实时同步。
- **快捷键**：`Alt+Shift+V` 开关面板。

## 📦 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展；
2. Tampermonkey 控制面板 → 「+」新建脚本 → 粘贴 `text-vault.user.js` 全部内容并保存；
3. 或直接把 `text-vault.user.js` 拖入浏览器，由 Tampermonkey 接管安装。

## 🕹 使用

| 动作 | 操作 |
| :--- | :--- |
| 记录选中文本 | 选中文字 → 点浮出的「✚ 记」按钮 |
| 记录剪贴板内容 | 油猴图标菜单 →「➕ 记录选中文本 / 剪贴板」（无选中文本时生效） |
| 打开 / 关闭面板 | 点悬浮球，或 `Alt+Shift+V`，或油猴菜单「📂 打开 / 收起面板」 |
| 写入输入框 | 先聚焦目标输入框，再点面板条目 |
| 复制到剪贴板 | 没有聚焦输入框时直接点条目；或点条目上的 ⧉ |
| 编辑 / 删除 / 置顶 | 条目右侧 ✎ / ✕ / ★（悬停条目显示） |
| 新增 | 面板右上「＋」，`Ctrl+Enter` 保存，`Esc` 取消 |
| 清空 | 面板左下「清空全部」，3 秒内再点一次确认 |
| 移动悬浮球 | 按住拖动，松开自动记忆位置 |

## ⚙️ 配置

脚本头部常量可按需修改：

| 常量 | 默认值 | 说明 |
| :--- | :--- | :--- |
| `MAX_ENTRIES` | `1000` | 条目上限，超出优先淘汰最旧的未置顶条目 |
| `MAX_TEXT_LEN` | `20000` | 单条文本上限，超出截断并标注 |
| `DEDUPE` | `true` | 重复记录改为置顶刷新而非新增 |
| `SNAP_BTN` | `true` | 是否启用选中文本后的浮出按钮 |
| `HOTKEY_CODE` | `'KeyV'` | 热键为 `Alt+Shift+<code>` |

数据存放在油猴脚本存储（键 `textVaultEntries`），不出本机、无任何网络请求。

## 🧪 本地开发

`dev/` 目录提供了一套 GM API shim,无需安装 Tampermonkey 即可在纯浏览器里跑通全部交互：

```bash
cd text-vault
python3 -m http.server 8642
# 手动体验:打开 http://localhost:8642/dev/test.html
node dev/e2e.cjs        # 37 项端到端断言(选区记录/写入/复制/编辑/撤销/去重/清空/热键/拖动)
node dev/screenshots.cjs # 生成面板/浮出按钮/暗色模式截图
```

shim 会把 `GM_*` 映射到内存对象并 mock 剪贴板读取（置 `window.__denyClipboard = true` 可模拟权限拒绝），同时捕获脚本的 closed shadow root（`window.__tv`）供测试定位内部元素；`window.TextVault.__debug` 暴露存储与菜单状态供断言。
